项目目的与范围

Karpathy 三层模型 · 原始素材 → Wiki 知识库 → Schema/治理

🎯 项目目的

  • 构建组织"Company Brain"：将 OneDrive 散落文档持续编译为结构化、低矛盾、可追溯的 Wiki
  • 查询响应较 RAG 缩短 ≥ 50%，事实一致性 ≥ 95%
  • ≥ 90% 维护工作（摘要/链接/矛盾标记/时效）由 LLM Agent 自动完成
  • 覆盖 5,000 名活跃用户，每用户 1,000 个源文件（共约 500 万份）

✅ 范围内 / ❌ 范围外

范围内

  • Web 前端、Entra ID SSO/MFA/RBAC、OneDrive 委托接入
  • Ingest / Query / Lint 三大 LLM 工作流
  • 结构化 Wiki（双向链接、版本、元数据）+ 混合检索 + 治理

范围外

  • 外部公开访问、非 OneDrive 连接器（SharePoint/Confluence/Slack…）
  • 对源文件回写、模型微调、原生移动端、实时多人协同
